# Repository instructions

- Use ASD-STE100 Simplified Technical English in user-facing text.
- Run `make test` after a code change.
- Run `make lint` after a packaging change.
- Keep tests in `test/`.
- Keep each commit limited to one purpose.
- Preserve the existing Debian package structure.

## Agent skills

### Issue tracker

Issues are local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout. See `docs/agents/domain.md`.
